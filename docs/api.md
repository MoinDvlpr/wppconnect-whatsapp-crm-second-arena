# REST API
Base `/api/v1`. Auth: `x-api-key: <key>` or `Authorization: Bearer <key>` or browser cookie. Roles ADMIN/OPERATOR/VIEWER; keys may be restricted to sessions. Most WhatsApp endpoints need `?sessionId=`.
Interactive docs: `/api/docs` (Swagger UI) · JSON: `/api/docs?format=json` or `/api/v1/openapi.json` · route list: `/api/v1/developer/routes`.
Main resources: `/health`, `/stats`, `/sessions[/:id/(status|qr|start|stop|restart|logout|sync|diagnostics|logs)]`, `/chats[/:id/(messages|presence|seen|typing|archive|pin|mute)]`, `/messages[/:id/(media|react|forward|star|reactions|votes)]`, `/contacts[/import|/export|/check|/:id/(whatsapp|block)]`, `/groups[/:id/…]`, `/labels[/native]`, `/templates[/render]`, `/campaigns[/:id/(start|pause|resume|cancel|retry|recipients|analytics)]`, `/webhooks`, `/automation/rules`, `/profile`, `/catalog`, `/status`, `/channels`, `/developer/(capabilities|events|queue|database)`, `/api-keys`, `/users`, `/settings`, `/logs/(system|audit)`, `/search`, `/uploads`, `/admin/(backup|restore)`.
Realtime: `GET /api/events` (SSE). Response envelope `{success, data}` / `{success:false, error:{code,message,details}}`; codes include VALIDATION_ERROR, UNAUTHORIZED, FORBIDDEN, NOT_FOUND, SESSION_NOT_READY, UNSUPPORTED, RATE_LIMITED, TEMPLATE_MISSING_VARIABLES, INVALID_TRANSITION.
